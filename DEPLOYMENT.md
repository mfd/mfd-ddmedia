# Самостоятельное обновление бота

Эта инструкция относится к текущему серверу `aiagent@88.218.93.204`. Код проекта находится на Mac в папке `bot`. Секреты и скачанные файлы хранятся на сервере вне папки приложения и в пакет обновления не входят.

## Один запуск с Mac

Откройте Терминал на Mac и выполните:

```bash
bash /Users/kkash/Documents/ChatGPT/life/bot/publish.sh
```

Скрипт сам проверит синтаксис и тесты, упакует текущий код, загрузит его на сервер, сохранит копию предыдущей версии и перезапустит `media-bot.service`. При запросе SSH введите пароль пользователя `aiagent`; при запросе `sudo` введите его ещё раз. Пароль не сохраняется в проекте и не должен появляться в команде.

После успешного завершения скрипт напечатает `Deployed ГГГГ.ММ.ДД.ЧЧ.ММ` и состояние службы. Боту также придёт уведомление о завершении работ. Если проверка после перезапуска не пройдёт, скрипт вернёт предыдущую версию.

## Проверка после обновления

В Telegram отправьте боту `/admin`: указанная версия должна совпадать с версией в первой строке `bot/CHANGELOG.txt`. Затем отправьте `/status` и пробную ссылку на короткое видео. На сервере состояние можно проверить так:

```bash
ssh aiagent@88.218.93.204
systemctl status media-bot.service --no-pager
journalctl -u media-bot.service -n 50 --no-pager
```

Для выхода из SSH выполните `exit`. Если скрипт завершился с ошибкой, сохраните его вывод и проверьте журнал службы. Не публикуйте в журнале и переписке содержимое закрытого файла `~/.config/youtube-bot/secrets.env`.

## Подключение Яндекс Музыки

Для полных треков нужен ваш аккаунт Яндекс Музыки с действующей подпиской Плюс. В новой версии это настраивается из Telegram: откройте `/admin` → «Яндекс Музыка» → «Подключить / обновить аккаунт». Бот пришлёт владельцу ссылку и одноразовый код. Откройте ссылку, подтвердите вход в аккаунт с подпиской Плюс и дождитесь сообщения об успешном подключении. Сам токен бот не показывает; он сохраняется в закрытом файле на сервере, а новые запросы начинают использовать его сразу.

Если админ-панель недоступна, можно выполнить запасной способ по SSH:

```bash
/home/aiagent/media-bot-venv/bin/python /home/aiagent/media-bot-app/yandex_auth.py
```

Скрипт покажет адрес Яндекса и короткий код. Откройте адрес в собственном браузере, войдите в свой аккаунт и подтвердите код. Скрипт сам сохранит токен в закрытом файле `~/.config/youtube-bot/secrets.env`; пароль и токен не копируйте в чат. После этого выполните `sudo systemctl restart media-bot.service`. Токен может истечь — в таком случае подключите аккаунт заново. Если аккаунту доступен только фрагмент конкретного трека, бот сообщит об этом вместо отправки неполного файла.
